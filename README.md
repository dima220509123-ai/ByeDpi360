# Сборка byedpi.xex через GitHub (Linux ставить НЕ надо)

Этот архив — готовый проект. Сборка идёт **в облаке GitHub**, у вас на ПК ничего устанавливать не нужно.

## Шаг 1. Создайте репозиторий

1. Зайдите на **github.com** под своим аккаунтом.
2. Нажмите зелёную кнопку **New** (или `+` → `New repository`).
3. Название: `byedpi-x360-build`. Остальное не трогайте, нажмите **Create repository**.

## Шаг 2. Загрузите файлы

1. Распакуйте присланный `github-build.zip` в любую папку.
2. На странице репозитория нажмите **uploading an existing file** (или `Add file` → `Upload files`).
3. Перетащите **все файлы и папку `.github`** из распакованной папки в окно загрузки.
   Важно: папка `.github` должна загрузиться целиком — в ней лежит workflow.
4. Нажмите **Commit changes**.

## Шаг 3. Дождитесь сборки

1. Нажмите вкладку **Actions** сверху.
2. Слева выберите **Build byedpi.xex**, справа — последний зелёный/жёлтый запуск.
3. Через 2–5 минут появится зелёная галочка. Если красный — скопируйте лог и пришлите мне.
4. Нажмите на этот запуск → внизу **Artifacts** → **byedpi-xex** → скачайте ZIP.
5. Распакуйте скачанный архив — внутри будет `byedpi.xex`.

## Шаг 4. Залить на консоль

1. Положите `byedpi.xex` в папку `out` рядом с `deploy.ps1` из основной папки проекта.
2. Скопируйте `byedpi.ini.example` → `out/byedpi.ini`.
3. Выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy.ps1 -Password <ваш_пароль>
```

4. В `Hdd1:\launch.ini` заполните свободный слот:

```ini
plugin5 = Hdd:\HDD\byedpi.xex
```

5. Перезагрузите консоль. Проверьте `Hdd:\byedpi.log`.

## Если сборка не прошла

Пришлите скрин лога из Actions — я поправлю (`powerpc-linux-gnu` может отличаться на раннере, или адрес `BASE` надо сменить).

## Что здесь делается

Плагин перехватывает `NetDll_send` (ординал 22) в `xam.xex` и разбивает первый TLS ClientHello на 2 байта + остаток. Поскольку Tube360 использует сокеты xsdk, которые идут через экспорты XAM, это должно затронуть и её HTTPS-трафик.
